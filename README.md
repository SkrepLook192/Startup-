## Шаг 1. Актуализация ценностного предложения

### Ценностное предложение (операционализированное)

> **Для** уставших профессионалов 25–35 лет с доходом $1500–4000/мес
>
> **в ситуации** «вечер после работы, нет сил даже выбирать категорию хобби, одному скучно»
>
> **решение** Hobby Worlds обеспечивает первое задание за 30 секунд через чат с AI-персонажем и безопасный поиск онлайн-напарника
>
> **улучшая** частоту начала хобби с 0 до 3–4 раз в неделю и снижая отток на 40%
>
> **по сравнению с** Habitica (устаревший дизайн, долгий вход) и Fabulous (15-минутный онбординг)
>
> **при условиях** бесплатного входа (freemium) и заданиях не дольше 5 минут.

### Почему пользователь поверит (основания)

| № | Основание | Доказательство |
|---|-----------|----------------|
| 1 | **AI-классификация работает** | Прототип на 200 диалогах дал точность >80% при определении мира |
| 2 | **Бесплатный вход — риск нулевой** | Базовый функционал бесплатен, Premium только после 5 заданий |
| 3 | **Персонаж вызывает эмпатию** | В тестах 8 из 10 сказали «как будто друг подбадривает» |

## Шаг 2. Декомпозиция ценности в пользовательский сценарий

### Основной сценарий (первое использование)

| Шаг | Действие | Что происходит | Время |
|-----|----------|----------------|-------|
| 1 | **Триггер** | Пользователь вспоминает о заброшенном хобби (вечер, листает TikTok) | — |
| 2 | **Скачивание** | Устанавливает приложение из App Store / Google Play | 30 сек |
| 3 | **Регистрация** | Вводит номер телефона или через VK | 20 сек |
| 4 | **Встреча с персонажем** | Персонаж говорит: «Привет! Напиши, что давно хотел сделать?» | 5 сек |
| 5 | **Ввод цели** | Пользователь пишет: «Хочу играть на гитаре, но лень» | 10 сек |
| 6 | **AI-классификация** | Персонаж отвечает: «Отлично! Твой мир — Музыка. Первое задание: возьми гитару в руки на 2 минуты» | 3 сек |
| 7 | **Выполнение задания** | Пользователь выполняет задание (2 минуты) | 2 мин |
| 8 | **Ачивка** | Персонаж поздравляет, выдаёт ачивку «Первый аккорд». 3D-мир слегка меняется | 5 сек |
| 9 | **Предложение напарника** | «Хочешь найти напарника, чтобы вместе учиться?» → кнопка «Да» | 5 сек |
| 10 | **Поиск напарника** | Приложение показывает 3–5 онлайн-напарников такого же уровня | 10 сек |
| 11 | **Фиксация результата** | Пользователь выбирает напарника, отправляет запрос. Мир запоминает прогресс | 10 сек |

**Общее время до первой ачивки:** ~3 минуты

### Альтернативный сценарий: повторное использование (Day 2)

| Шаг | Действие |
|-----|----------|
| 1 | Пользователь открывает приложение |
| 2 | 3D-мир показывает изменения (вчерашняя ачивка) |
| 3 | Персонаж: «С возвращением! Вчера ты сделал первый шаг. Сегодня задание: найти 3 аккорда в YouTube (5 минут)» |
| 4 | Пользователь выполняет |
| 5 | Получает ачивку «Искатель аккордов» |
| 6 | Персонаж: «Твой напарник Анна тоже выполнила задание! Напиши ей?» |
| 7 | Пользователь отправляет сообщение напарнику |

### Альтернативный сценарий: ошибка (AI не понял)

| Шаг | Действие |
|-----|----------|
| 1 | Пользователь пишет: «Хочу что-то интересное» |
| 2 | AI не может определить мир (уверенность <60%) |
| 3 | Персонаж: «Расскажи чуть подробнее. Это про творчество, спорт или что-то ещё?» |
| 4 | Пользователь выбирает из 3 уточняющих вариантов |
| 5 | AI определяет мир и выдаёт задание |

## Шаг 4. Формирование backlog MVP

### User Stories для Core (8 штук)

| ID | User Story | Acceptance Criteria | Priority | Риски |
|----|------------|---------------------|----------|-------|
| **US-1** | Как пользователь, я хочу написать персонажу фразу о моём хобби, чтобы не выбирать из списка | 1. Чат открывается сразу после регистрации<br>2. Поле ввода принимает текст до 200 символов<br>3. Персонаж отвечает в течение 3 секунд<br>4. При непонятном запросе — уточняющий вопрос | Must | AI может не понять → нужен fallback |
| **US-2** | Как пользователь, я хочу, чтобы AI определил мой мир из 8 категорий, чтобы я не думал | 1. Точность определения >80% на тестовых фразах<br>2. Пользователь может изменить мир вручную<br>3. Мир отображается в профиле | Must | Качество классификации |
| **US-3** | Как пользователь, я хочу получить первое задание на 5 минут, чтобы не пугаться сложности | 1. Задание не требует доп. оборудования<br>2. Таймер обратного отсчёта<br>3. Кнопка «Выполнил» активна после таймера<br>4. Задание зависит от мира | Must | Генерация контента |
| **US-4** | Как пользователь, я хочу видеть 3D-шар, который меняется от моих действий, чтобы чувствовать прогресс | 1. Шар вращается по свайпу<br>2. После ачивки шар меняет цвет/добавляет элемент<br>3. Анимация изменения <1 секунды | Must | 3D-производительность |
| **US-5** | Как пользователь, я хочу получать ачивки за выполненные задания, чтобы чувствовать мотивацию | 1. Ачивка выдаётся после нажатия «Выполнил»<br>2. Всплывающее уведомление с анимацией<br>3. Ачивки сохраняются в профиль | Must | Дизайн ачивок |
| **US-6** | Как пользователь, я хочу найти онлайн-напарника с таким же уровнем, чтобы не стесняться | 1. Поиск по интересу (миру)<br>2. Фильтр «только начинающие»<br>3. Карточки напарников с аватаркой и рейтингом<br>4. Кнопка «Отправить запрос» | Must | Холодный старт (нет пользователей) |
| **US-7** | Как пользователь, я хочу получать push-уведомления о новых заданиях, чтобы не забывать | 1. Настройка времени уведомлений<br>2. Уведомление в 20:00 «Твоё задание на сегодня»<br>3. Переход в приложение по тапу | Should | Надоедливость |
| **US-8** | Как пользователь, я хочу оценить напарника после общения, чтобы чувствовать безопасность | 1. После чата — запрос оценки<br>2. Оценка от 1 до 5 звёзд<br>3. Рейтинг отображается в профиле | Could | Модерация |

## Шаг 5. Нефункциональные требования

| № | Категория | Требование | Приоритет |
|---|-----------|------------|-----------|
| 1 | **Производительность** | Время ответа AI-персонажа <3 секунд (95% запросов) | Must |
| 2 | **Производительность** | Время загрузки 3D-мира <2 секунд на iPhone 11 и выше | Must |
| 3 | **Доступность** | Офлайн-режим: просмотр последнего задания и ачивок без интернета | Should |
| 4 | **Безопасность** | Номер телефона не передаётся третьим лицам, шифрование в покое | Must |
| 5 | **Безопасность** | Чат с напарником — премодерация мата и угроз (regex + жалобы) | Should |
| 6 | **Надёжность** | Данные пользователя сохраняются при падении приложения (автосохранение) | Must |
| 7 | **Совместимость** | iOS 15+ и Android 11+ | Must |
| 8 | **Доступность** | Шрифты не менее 14pt, контрастность 4.5:1 (WCAG AA) | Could |
| 9 | **Масштабируемость** | Архитектура поддерживает до 100k MAU без переписывания | Must |
| 10 | **Хранение** | Логи AI-диалогов хранятся 30 дней для дообучения | Should |

## Шаг 6. Контроль согласованности

### Проверка 1: Каждый шаг сценария поддержан функцией

| Шаг сценария | Функция | Статус |
|--------------|---------|--------|
| 1. Триггер | (вне продукта) | ✅ N/A |
| 2. Скачивание | (маркетинг) | ✅ N/A |
| 3. Регистрация | US-0 (регистрация) | ✅ Support |
| 4. Встреча с персонажем | US-1 (AI-чат) | ✅ Core |
| 5. Ввод цели | US-1 (AI-чат) | ✅ Core |
| 6. AI-классификация | US-2 (классификация) | ✅ Core |
| 7. Выполнение задания | US-3 (задание 5 мин) | ✅ Core |
| 8. Ачивка | US-5 (ачивки) + US-4 (3D-мир) | ✅ Core |
| 9. Предложение напарника | US-6 (поиск) | ✅ Core |
| 10. Поиск напарника | US-6 (поиск) | ✅ Core |
| 11. Фиксация результата | US-4 (3D-мир) + US-5 (ачивки) | ✅ Core |

### Проверка 2: Каждая Core-функция объясняется ценностью

| Core-функция | Какую ценность даёт | Связь с проблемой |
|--------------|---------------------|-------------------|
| AI-чат | Лёгкий вход | «Нет сил выбирать» |
| Классификация | Не нужно думать | «Нет сил выбирать» |
| Задание 5 мин | Быстрый дофамин | «Не могу начать» |
| 3D-мир | Визуальный прогресс | «Нет прогресса» |
| Ачивки | Мотивация | «Нет наград» |
| Поиск напарника | Компания | «Одному скучно» |

### Проверка 3: Нефункциональные требования не противоречат MVP

| Требование | Совместимость с MVP | Комментарий |
|------------|---------------------|-------------|
| Время AI <3 сек | ✅ | Используем GPT API или локальную модель |
| 3D <2 сек | ✅ | Three.js с оптимизацией |
| Офлайн-режим | ⚠️ | Отложен в Support, но архитектура позволяет |
| Безопасность | ✅ | Стандартные практики |
| Масштабируемость до 100k | ✅ | Node.js + PostgreSQL вывозят |
| iOS 15+ / Android 11+ | ✅ | React Native позволяет |
