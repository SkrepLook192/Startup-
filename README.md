
# HobbySphere — Практическое занятие №24

![status](https://img.shields.io/badge/status-pre--seed-7C3AED) ![model](https://img.shields.io/badge/model-freemium-22C55E) ![growth](https://img.shields.io/badge/growth-PLG%20%2B%20community-22D3EE)

> **Тема:** Формирование стратегии роста и финансового плана. Оценка собственной компании.  
> **Проект:** мобильное приложение с AI-персонажем, микроквестами по хобби, поиском напарника и 3D-миром прогресса.

## TL;DR

**Главный драйвер роста:** Product-led growth + community loop.  
**North Star Metric:** completed hobby quests per active user per week.  
**Base scenario M12:** 978 paid users, MRR около 390 тыс. ₽.  
**Потребность в финансировании:** около 8,3 млн ₽.  
**Оценка компании:** 20–37 млн ₽ pre-money, рабочий ориентир 25–30 млн ₽.

## 1. Ядро роста

```text
AI prompt -> micro quest -> completed action -> visual reward -> share/invite -> new user -> new quest
```

| Горизонт | Цель | Метрики |
|---|---|---|
| 0–3 месяца | Запустить MVP и доказать первый completed action | 1 500 регистраций, activation >35%, 500 completed quests, D7 >18% |
| 3–12 месяцев | Масштабировать loop и проверить Premium | 75 000 регистраций, 978 paid users, MRR ≈ 390 тыс. ₽ |

## 6. План повышения оценки на 4–8 недель

- Поднять activation rate через A/B AI-онбординга.
- Увеличить D7/D30 retention через streaks, редкие предметы и цепочки квестов.
- Проверить Premium paywall после 3/5/7 выполненных квестов.
- Снизить CAC через UGC-карточки и referral.
- Проверить social matching в 2 городах с рейтингом и безопасными правилами.
