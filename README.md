Кратко: HobbySphere помогает человеку начать отложенное хобби через AI-персонажа, микро-квесты, поиск напарников и визуальный прогресс в виде красивого 3D мира-шара.

1. О проекте
HobbySphere — мобильное приложение, которое превращает «лень и откладывание» любимых хобби в игровой квест. Пользователь пишет естественным языком, чего хочет, а AI-персонаж предлагает первый маленький шаг, награду и возможность найти единомышленника рядом.
Документ оформлен как красивый README для GitHub: его можно использовать как основу для README.md, документации репозитория или презентационного описания проекта.
2. Проблема
У людей есть давние желания: научиться рисовать, начать бегать, собрать модель, читать больше книг, играть на гитаре. Но без структуры, дедлайнов и компании эти желания постоянно откладываются.
• нет легкого первого шага и понятного входа в хобби;
• одному скучно, нет подотчетности и поддержки;
• классические трекеры привычек выглядят слишком серьезно;
• прогресс не дает эмоциональной награды;
• сложно найти людей рядом с похожими интересами.
 
3. Решение
Блок	Что делает
AI-персонаж	Понимает цель обычным языком и превращает ее в понятные микро-квесты.
3D мир-шар	Визуально растет от прогресса: появляются локации, домики, предметы и редкие награды.
Напарники рядом	Помогает найти человека с похожим хобби и уровнем мотивации в своем городе.
Ачивки и streak	Дофаминовая награда за маленькие действия и совместные челленджи.
Solo mode	Режим одиночных квестов, если в регионе пока мало пользователей.
Безопасность	Жалобы, рейтинг, приватность и ограничения для офлайн-встреч.

4. Основной пользовательский сценарий
Пользователь: Иван, 28 лет, офисный работник. Ситуация: пятничный вечер, он устал и листает TikTok. Вспоминает, что год назад хотел играть на гитаре. Действие: пишет в приложении: «хочу играть на гитаре, но лень». Результат: AI-персонаж дает микро-квест на 5 минут, мир-шар получает первую музыкальную локацию, а приложение предлагает найти напарника.

6. Ключевая функциональность
• AI-онбординг через естественный язык.
• Генерация микро-квестов на 5–15 минут.
• Визуальный 3D мир-шар, который развивается от прогресса.
• Поиск напарника по интересу, уровню и геолокации.
• Совместные квесты, ачивки, streak и редкие предметы.
• Соло-режим для решения проблемы холодного старта.
• Жалобы, рейтинг и ограничения для офлайн-встреч.

9. Быстрый запуск
# 1. Клонировать репозиторий
git clone https://github.com/username/hobbysphere.git
cd hobbysphere

# 2. Установить и запустить backend
cd backend
npm install
cp .env.example .env
npm run dev

# 3. Установить и запустить mobile app
cd ../mobile
npm install
npx expo start

11. Базовая модель данных
Сущность	Назначение
User	Профиль пользователя, город, интересы, настройки приватности.
Hobby	Категории хобби, уровни сложности, теги и стартовые шаблоны.
Quest	Микро-задания, цепочки квестов, награды и дедлайны.
WorldItem	Предметы, локации и улучшения для 3D мира-шара.
Achievement	Ачивки, streak, редкая награда и совместные достижения.
MatchRequest	Поиск напарника, совместные квесты и статусы приглашения.
Report	Жалобы, модерация и безопасность офлайн-встреч.

12. Метрики MVP
• Activation Rate — доля пользователей, которые дошли до первого задания и нажали «Выполнил».
• D1 / D7 Retention — возврат на следующий день и через неделю.
• Partner Search CTR — доля пользователей, которые нажали «Найти напарника».
• Quest Completion Rate — выполнение микро-квестов.
• Premium Conversion — переход в подписку после первых ачивок.

15. Статус проекта
Проект находится на стадии MVP-концепта / pre-seed. Основная гипотеза для проверки: AI-микрозадания и визуальный игровой прогресс увеличивают выполнение первого действия и возврат пользователя на следующий день.
